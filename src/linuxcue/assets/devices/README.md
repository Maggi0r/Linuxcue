Place optional device card images here.

linuxcue loads these files automatically when present:

- `k95.png` for Corsair K95 RGB Platinum
- `m65.png` for Corsair M65 Pro RGB
- `virtuoso-se.png` for Corsair Virtuoso SE
- `receiver.png` for the Virtuoso wireless receiver

PNG, WEBP, JPG, and JPEG are supported. Use images you own or are allowed to use.
